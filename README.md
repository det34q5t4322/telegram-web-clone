# 🚀 Telegram Web Clone Messenger (Full-Stack Real-Time Chat)

An ultra-rich, responsive, pixel-perfect clone of **Telegram Web** built with Node.js, Express, Socket.io, and Vanilla CSS/JS. Supports real-time messaging, voice notes, stickers, GIFs, polls, audio/video call UI, themes, and instant zero-config public tunneling.

## ✨ Features

- 💬 **Real-Time Instant Messaging**: Low latency WebSocket communication via Socket.io.
- 🏷️ **Telegram Sticker Packs & GIFs**: Animated stickers (Duck, Pepe, Cats) and Giphy integration.
- 🎤 **Voice Notes Recording**: Browser Web MediaRecorder API with audio waveform visualization & 1.0x / 1.5x / 2.0x speed multiplier.
- 📊 **Live Polls & Surveys**: Create interactive polls with real-time voting percentage bars.
- 🤖 **Telegram AI Assistant (@Telegram_AI)**: Built-in AI bot auto-responding to user questions.
- 🔖 **Saved Messages ("Избранное")**: Personal room for notes and bookmarking files.
- 📌 **Pinned Messages Header**: Sticky header banner for pinned messages with auto-scroll.
- 📞 **Voice & Video Calling UI**: WebRTC call signaling with Telegram ringtone modal.
- 🎨 **Wallpaper Selector**: Dynamic chat background switcher (Midnight, Sunset, Cyberpunk, Classic).
- 🔍 **In-Chat Message Search**: Instant keyphrase filtering.
- 🌐 **Instant Global Tunnel**: Built-in Localtunnel integration generating a live public HTTPS link for friends in other cities.

## 🛠️ Quick Start (Local Launch)

```bash
# 1. Clone the repository
git clone https://github.com/your-username/telegram-web-clone.git
cd telegram-web-clone

# 2. Install dependencies
npm install

# 3. Start the server
npm start
```

Open `http://localhost:3000` in your browser!
